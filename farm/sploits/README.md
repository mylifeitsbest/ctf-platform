# farm/sploits

Сюда кладёте рабочие сплойты. Ферма подхватывает любой файл `*_sploit.py`, в котором есть:

```python
SERVICE = "notes"            # какой сервис атакует
def exploit(host, port):     # вернуть список найденных флагов
    ...
    return flags
```

- `template_sploit.py` — шаблон (ферма его игнорирует, т.к. `SERVICE = None`).
- Эталонные решения лежат в `../exploits_reference/`. **Сначала попробуйте сами**, потом сверяйтесь.
- Быстро залить эталоны в ферму: `scripts\load_reference_sploits.ps1`.

Советы:
- таймауты 2–3с — целей много, раунд короткий;
- не падайте на одной цели (оборачивайте в try), ферма и так ловит исключения;
- флаг = `[A-Z0-9]{31}=`, ферма сама отфильтрует мусор.
